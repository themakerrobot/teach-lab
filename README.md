# Teach Lab

**브라우저에서 바로, 내가 보여 준 것으로 AI를 가르쳐요.**

Teach Lab 은 어린이를 위한 수업용 웹앱입니다. 웹캠에 물건·손·표정·몸동작을
보여 주거나 마이크에 소리를 내어 예시를 모으면, 몇 초 만에 작은 AI가
학습됩니다. 배운 모델을 바로 시험하고, 파일 하나로 내보내고,
**파이썬 코드로 받아서** 내 프로그램에 넣을 수 있습니다.

설치도 가입도 없습니다. 모든 것이 브라우저 안에서 돌아가고, **찍은 사진은
컴퓨터 밖으로 나가지 않습니다.**

> 헤더의 **EN** 버튼을 누르면 화면 전체가 영어로 바뀝니다.

Sense Lab · 파이보 랩의 자매 서비스로, 화면 규격은 셋이 같습니다.

## 무엇을 보고 배울까요

다섯 가지 중에 고릅니다.

| 소스 | 무엇을 보나요 | AI가 보는 숫자 |
|---|---|---|
| **이미지** | 사진 그대로 (물건·카드·그림) | 1024개 |
| **손** | 손가락 관절 21점 (한 손 / 두 손) | 63 · 126개 |
| **얼굴** | 표정 점수 (웃기·입 벌리기 등) | 52개 |
| **포즈** | 몸의 관절 (상반신 / 전신) | 75 · 99개 |
| **소리** | 마이크 소리 (박수·휘파람·말소리) | 521개 |

## 학습실 — 나만의 AI 모델 만들기

1. 무엇을 보고 배울지 고릅니다.
2. 맞히고 싶은 **종류**를 만듭니다 (예: 사과 / 바나나 / 아무것도 없음).
3. 카메라나 마이크를 켜고 종류를 고른 뒤, **버튼을 꾹 눌러** 예시를 모읍니다.
   종류당 20~40개면 충분합니다. 이미지 소스는 **사진 파일**을 넣어도 됩니다.
4. **배우기 시작**을 누르면 몇 초 만에 끝나요. 진행 그래프와 맞힌 비율,
   그리고 **헷갈린 표**가 나옵니다 — 어떤 종류끼리 헷갈렸는지 보고 예시를
   다시 모을 수 있어요.
5. 모델에 이름을 붙여 저장합니다.

이미지 소스의 카메라 화면은 **AI에게 넣는 그림 그대로**입니다
(가운데 정사각형, 거울). Teachable Machine 과 같은 방식이라 보이는 대로
배웁니다. 손·얼굴·포즈는 영상 위에 뼈대를 겹쳐 보여 줍니다.
그 밑의 **"AI가 보는 숫자"** 패널에는 지금 뽑히는 숫자가 실시간으로 나와요.

## 시험실 — 잘 배웠는지 보기

저장한 모델을 골라 카메라 앞에 보여 주거나 소리를 내면 종류별 확률이 막대로
나옵니다. **확신 정도** 슬라이더보다 덜 확실하면 *"모르겠어요"* 라고
답합니다. 이미지 모델은 사진 파일 하나로 시험해 볼 수도 있어요.

## 보관함 — 만든 것 지키기

저장한 모델이 모두 여기 있습니다. 이름을 바꾸고, **이어서 배우기**로 예시를
더 모아 다시 학습하고, 두 가지로 내보낼 수 있어요.

| 내보내기 | 받는 것 | 쓰는 곳 |
|---|---|---|
| **프로젝트 파일** (`.teachlab.zip`) | 모델 + 예시 + 썸네일 | 다른 컴퓨터의 Teach Lab 에 놓으면 그대로 복원 |
| **파이썬** (`-python.zip`) | 모델 + 임베더 + 실행 코드 | `pip install teachlab` 후 바로 실행 |

재부팅하면 초기화되는 교실 PC 에서는 꼭 내보내기를 써 두세요.

## 파이썬으로 이어서 쓰기

```bash
unzip 과일맞히기-python.zip && cd 과일맞히기-python
pip install teachlab
python predict.py 사진.jpg        # 사진 한 장 분류
python webcam.py                  # 웹캠으로 실시간 분류
```

이미지 모델은 `numpy`·`Pillow`·`LiteRT` 만 받으면 됩니다 (약 110MB).
TensorFlow 도 MediaPipe 도 필요 없어요. 손·얼굴·포즈·소리 모델은
`pip install "teachlab[all]"` 로 MediaPipe 까지 받습니다.

```python
from teachlab import ImageClassifier

clf = ImageClassifier("model")
result = clf.predict_file("사진.jpg")
print(result.label, result.score)
```

인터넷도 클라우드 API 도 필요 없습니다. 임베더(.tflite)까지 zip 안에 들어
있어서 기기 안에서 전부 돕니다.

> 웹캠은 거울로 두고 배우기 때문에, 파이썬에서도 웹캠 프레임은
> `predict_webcam(frame)` 으로 넣어야 방향이 맞습니다. 거울이 아닌 카메라(로봇 카메라 등)라면 `predict(frame)` 을 쓰세요.

자세한 것은 [`python/README.md`](python/README.md) 를 보세요.
